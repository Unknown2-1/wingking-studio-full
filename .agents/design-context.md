# WINGKING STUDIO — Design Context

> Project design direction for posters, site artwork, editorial layouts and UI.
> This is *brand guidance*, not an instruction to automatically deploy or alter code.

## Brand
- Name: **WINGKING STUDIO**.
- Domain: https://wingking-studio.vercel.app/
- Origin / audience: local indie-music scene in Purwokerto, musicians, bands and music fans.
- Site content: indie band profiles, pricing information, stories, releases, clips, upload/submission, booking through contact person.
- Existing logo is the brand's visual anchor: retain the **WINGKING STUDIO** name and original wing emblem. Never invent a replacement logo.

## Verified website colors
The original public CSS uses:
- Warm cream background: `#F9F5E8`
- Deep forest ink: `#243528`
- Coral pink: `#FF637B`
- Forest green: `#236D50`
- Lime: `#C3E878`
- Butter yellow: `#FFCF54`

Use cream/forest as primary. Select ONE accent (coral/lime/yellow) per design, with other colors as secondary, never maximal saturation everywhere.

## Typography
- Website uses **DM Sans** and **Outfit**.
- Headline: substantial type, deliberate rhythm, distinctive line breaks.
- Body text: readable at actual size, strong contrast, short Indonesian copy.
- Maximum two typefaces. No placeholder gibberish or unchecked generated text.

## Art direction
- Quirky **indie music editorial**, tactile risograph / screenprint, thick but controlled outlines.
- Human-designed composition: intentional grid, whitespace, asymmetric editorial balance, one dominant focal point.
- Use one clear hero illustration (e.g. a watermelon character with a playful music reference) rather than scattered stickers.
- Keep collage/storytelling visual if supported by actual content; avoid random emojis, crowns, audio icons, sparks and stock illustrations everywhere.
- Animation should be restrained and purposeful on website, no excessive motion.
- Do not distort or replace the original logo.

## Poster A4 requirements
- Portrait A4 210 × 297 mm, 300 DPI raster approximately 2480 × 3508 px; for print use 3 mm bleed per side and safe text margins.
- Hero: brand/title + one hero illustration; short description; at most 3–4 key website features; one strong URL/QR call to action.
- Key website info: band profiles, releases, behind-the-scenes video, send your band, contact booking.
- Booking notice: **maksimal H-1** (only if appropriate and verified for requested poster).
- Primary CTA: **wingking-studio.vercel.app**.
- Verify URLs/spelling and logo placement manually at 100% zoom before delivering files.
- Prefer editable typography/layout over baking every text element into an AI-generated picture.

## Anti-slop QA gate
- Can a viewer understand it in 3 seconds from 2 metres?
- Is there ONE clear thing to read first?
- Are colors and iconography recognizably Wingking rather than a generic festival?
- Is the copy exactly correct? If image-generation fails typography, overlay text using code/artifact tools.
- Is it printable, with contrast and proper safe margins?
- Did someone compare the draft to actual site logo/CSS and not simply guess the palette?
- Produce 2–3 genuinely different art directions before finalising an important client design; do not promise correctness without reviewing the result.
